# SIH26099 — UI Specification

## Principle
Prioritize clarity, technical evidence and demonstrability.

## Routes
- `/upload`
- `/dashboard`
- `/matches/:id`
- `/common-materials`

## Upload Screen
```text
Material Harmonization

Organization A
[ Upload CSV ]

Organization B
[ Upload CSV ]

[ Run Matching ]
```

## Dashboard
Show:
- Total Materials
- Equivalent
- Review
- Different

Table:
- Material A
- Material B
- Classification
- Confidence
- Status
- Action

## Match Detail
Show both descriptions, attribute comparison, confidence, score components, explanation and Approve/Reject actions.

## Common Materials
Show:
- Common material ID
- Canonical description
- Technical attributes
- Source records

## MVP Exclusions
No admin panel, authentication, role management, settings dashboard or advanced analytics.
